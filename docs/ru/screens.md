# Экраны

## Основные экраны

### Splash

- инициализирует стартовый flow
- загружает локальное состояние приложения
- решает, куда идти дальше: onboarding или основной контейнер

### Главный экран / обзор тестов

- показывает сводку по пользователю и точки входа в списки тестов
- открывает flow создания тестов и разборов

### Редактор теста

- создает новые тесты
- переименовывает и удаляет существующие

### Редактор вопросов

- создает и обновляет вопросы
- управляет вариантами ответов и флагами правильных ответов

### Список тестов

- показывает тесты выбранной категории
- поддерживает обычные, избранные и ошибочные подборки

### Настройка прохождения

- выбирает режим сессии
- настраивает таймер, перемешивание и количество вопросов

### Активная сессия

- отображает поток вопросов
- отслеживает прогресс
- применяет логику проверки ответов
- поддерживает безопасственный выход с подтверждением

### Экран результатов

- показывает итоговый результат
- отображает каждый отвеченный вопрос с корректным разбором
- позволяет перейти к дальнейшим действиям, например разбору ошибок или избранному

### Профиль и статистика

- показывает локальную агрегированную статистику
- отображает версию приложения
- содержит настройки уведомлений и точки входа в review flow

### Экран импорта

- объясняет flow JSON-импорта
- служит точкой входа для создания теста из файла

## Навигационная модель

Проект использует typed back stack с сериализуемыми navigation key. Навигация выполняется через
общий `RootNavigation` и операции со стеком вроде `add()` и `removeLastOrNull()`.
