# Функциональность

## Основной сценарий

Tutor помогает пользователю создавать собственные наборы вопросов, проходить их в разных режимах и
разбирать ошибки с локальным сохранением прогресса.

## Основные возможности

### Создание тестов

- создание теста по названию
- последующее редактирование
- удаление теста с каскадной очисткой связанных данных

### Управление вопросами

- добавление и редактирование текста вопроса
- добавление, редактирование и удаление вариантов ответа
- поддержка одного или нескольких правильных ответов
- ограничение от 2 до 8 вариантов ответа
- сохранение порядка вопросов внутри теста

### Прохождение тестов

Поддерживаемые режимы:

- `Exam`
- `Workout`
- `Errors`
- `Favorites`

Доступные параметры перед стартом:

- таймер
- случайная выборка вопросов
- перемешивание вопросов
- перемешивание ответов
- показ правильного ответа сразу
- отдельная логика для вопросов с несколькими правильными вариантами

### Результаты и разбор

- сохранение каждой попытки
- разбор по каждому вопросу после завершения
- пометка ошибочных вопросов
- добавление вопросов в избранное

### Статистика

Приложение хранит локальную агрегированную статистику:

- количество завершенных тестов
- общее количество ошибок
- суммарное время
- дата первого запуска

### Импорт JSON

Tutor умеет создавать тест из входящего JSON-файла. Импорт парсит файл в `TestShareData`, создает
тест и добавляет вопросы с вариантами ответов.

### Уведомления

Локальные reminder-уведомления планируются через WorkManager для неактивных пользователей. Их можно
включать и выключать на экране профиля.

### UI и локализация

- светлая и темная темы
- несколько языковых наборов ресурсов
- общая дизайн-система в `:common_ui`
